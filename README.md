Модуль для анализа производительности веб-серверов. 

Программа должна обрабатывает список URL-адресов, имитируя отправку HTTP-запросов и замеряя время их выполнения.

Принимает список URL-адресов (задано в коде как слайс строк).

Параллельно обрабатывает каждый URL с помощью функции-заглушки, которая имитирует HTTP-запрос (используется time.Sleep со случайной задержкой).

Собирает результаты обработки (URL, статус «обработан», время выполнения).

Выводит агрегированный отчёт по всем обработанным URL-адресам.
